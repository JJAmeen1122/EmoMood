🌈 EmoMood - Mental Wellness Companion
https://via.placeholder.com/800x200/4CAF50/white?text=MindWell+-+Your+Mental+Wellness+Companion

A comprehensive mental wellness application built with Gradio that provides emotional support, crisis detection, mood tracking, and therapeutic activities through an intuitive web interface.

✨ Features
🛡️ Crisis Detection & Support
Advanced crisis detection with keyword and pattern matching

Immediate safety responses for harmful thoughts

24/7 crisis resources including 988 Suicide & Crisis Lifeline

Safety-focused messaging emphasizing life's value

💬 Emotional Support
AI-powered emotion analysis from text input

Personalized motivational messages for each emotion state

Therapeutic activity recommendations tailored to your current mood

Real-time emotional support and validation

📊 Wellness Dashboard
Interactive mood tracking with Plotly charts

Emotion distribution analysis through pie charts

Activity completion logging

Progress statistics and consistency metrics

🌿 Nature Healing
Science-backed nature therapy techniques

Mindful nature practices and exercises

Life-affirming outdoor activities

Seasonal awareness and grounding techniques

🎯 Supported Emotions
😰 Anxiety - Worry, nervousness, panic

😔 Sadness - Depression, hopelessness, low energy

😠 Anger - Frustration, irritation, rage

😫 Stress - Overwhelm, pressure, burnout

😊 Happiness - Joy, contentment, positivity

😴 Fatigue - Exhaustion, drained, low energy

🚀 Quick Start
Prerequisites
Python 3.8 or higher

pip (Python package manager)

Installation
Clone or download the repository

bash
git clone <your-repository-url>
cd mindwell-app
Install required packages

bash
pip install -r requirements.txt
Run the application

bash
python app.py
Access the application
Open your browser and go to: http://localhost:7860
